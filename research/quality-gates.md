# Quality gates

| Area | Gate |
|---|---|
| Source | Every ROM member classified by size and CRC; originals immutable |
| Runtime | Every supported title boots and completes representative missions |
| Fidelity | Audio, timing, slowdown profile, sprites and region behavior verified |
| Input | Keyboard and common gamepads support two local players |
| Profiles | DIP, controls, saves, shaders and authentic/free presets are isolated |
| LAN | Two physical same-subnet PCs complete co-op without Internet or accounts |
| Synchronization | Core/ROM/BIOS/config mismatch is detected before netplay |
| Replay | Input replay is deterministic for a pinned core/runtime version |
| Recovery | Corrupt/missing bytes are diagnosed, never silently substituted |
| Packaging | No ROM or BIOS byte is distributed |
