# Metal Slug Classics

Cross-platform preservation and launcher project for locally owned Neo Geo
Metal Slug data.

The original archives remain immutable. The project audits them by checksum,
normalizes compatible legacy layouts into derived sets under `work/`, and runs
them through maintained native emulators rather than NeoRAGEx.

Primary runtime: FinalBurn Neo. MAME is used as an independent preservation
oracle. Linux and Windows FBNeo builds are pinned locally during research.
